# Swarmathon Rover Alignment System

This software helps a **Swarmathon rover** accurately align with a designated drop-off area using **3D positional data** from [AprilTags](https://april.eecs.umich.edu/software/apriltag). The rover calculates the orientation required to position itself within a **1.5m x 1.5m square** and successfully deposit its resource (cube) within the designated perimeter.

Swarmathon is a **robotics and algorithm competition** designed to test autonomous rover systems. My team from [Durham Tech Community College](https://www.durhamtech.edu/news/durham-tech-takes-first-place-national-nasa-competition) won **first place in 2018** in this prestigious competition, showcasing our innovation in rover navigation and control systems.

## Features
- **Real-time rover positioning** based on AprilTag detection.
- **Automatic alignment** of the rover with a target area (1.5m x 1.5m square).
- **Efficient decision-making** to direct the rover’s movement towards the drop-off zone.
- **Swarmathon competition** background, demonstrating our team’s success in a national NASA competition.

## Technologies Used
- **AprilTags** for visual localization.
- **3D positional tracking** to compute rover orientation.
- **Custom software algorithms** for real-time navigation and alignment.

### Purpose
This system is designed to facilitate autonomous navigation for the Swarmathon rover, enabling precise alignment with a target drop-off zone. It’s part of a larger project aimed at improving autonomous swarm robotics capabilities, particularly in competitive environments like Swarmathon.
