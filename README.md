Use 3d positional locations of [April Tags](https://april.eecs.umich.edu/software/apriltag) in the outline a 1.5m x 1.5m square, to determine which direction a swarmathon rover should turn in order to deposit it's resouce (cube) within the perimeter of the square.

Swarmathon, at its core, is a programmaming and algorithm competition for which my college, [Durham Tech Community College, placed first in 2018](https://www.durhamtech.edu/news/durham-tech-takes-first-place-national-nasa-competition)
